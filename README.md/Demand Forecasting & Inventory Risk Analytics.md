# Demand Forecasting & Inventory Risk Analytics for a Beverage Distribution Network

## Overview

This project aims to analyze demand patterns across multiple beverage SKUs and warehouses to improve inventory planning.

The solution combines SQL, Python, Machine Learning, Excel, and Power BI to forecast demand, identify stockout risks, and recommend inventory policies.

---

## Business Problem

A regional beverage distribution network experiences:

- Frequent stockouts during festivals and promotions.
- Excess inventory of slow-moving products.
- High inventory holding costs.
- Seasonal demand fluctuations.

The objective is to forecast demand, predict stockout risk, and recommend inventory policies.

---

## Dataset

This project uses a synthetically generated dataset representing:

- 12 SKUs
- 4 Warehouses
- 104 Weeks of historical data
- Festival and summer seasonality
- Promotions
- Inventory levels
- Lead times
- Stockout events
